# f_fit

## Gemini API configuration

Provide a Gemini API key at run or build time instead of committing it:

```powershell
flutter run --dart-define=GEMINI_API_KEY=YOUR_GEMINI_API_KEY
```

Dart defines are embedded in the built client. Use a backend proxy and restrict
the key for production use.
